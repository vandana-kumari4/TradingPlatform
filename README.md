## ⚡ Quick Start

```bash
# Clone repository
git clone https://github.com/vandana-kumari4/TradingPlatform.git
cd TradingPlatform

# Install & run
npm install
npm run dev
```

**That's it!** Open [http://localhost:3000](http://localhost:3000) 🎉
